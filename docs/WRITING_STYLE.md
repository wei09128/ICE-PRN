# Wei manuscript writing preferences

Use this file at the start of future ICE-PRN editorial work; it records the user’s explicit preferences, not a promise that every new chat will retrieve them automatically.

Write concise scientific prose with familiar words and precise verbs. Keep the author’s conversational clarity in explanations, but use publication language in the manuscript. Each paragraph should state its question or purpose, report the answer, and explain the reason or implication where needed. Bridge logical gaps; do not make the reader infer why one analysis follows another.

Results should establish what was done and what follows from it. Include a brief method explanation when it helps readers understand the comparison. Move most counts, parameter settings and interval details to legends or Methods; keep only central quantitative anchors in prose. Do not repeat every result in Discussion.

Discussion should answer so what: what can another researcher now evaluate, how does this change interpretation, and which experiment would distinguish competing explanations? Treat A/B/K as a design and interpretation framework, not an identified mechanism. Separate prediction, annotation association and causal explanation.

Remove redundant panels and repeated caveats; retain mixed and negative evidence that changes the conclusion. Promote a supplementary result only when it advances the main argument, keeping the unfavorable comparisons beside it. Preserve full source data and retired analyses in an archive. Keep comparators, units, exploratory status and material limitations explicit. Avoid claims that a pathway is absent, learned mechanistically or destination-specific unless directly tested. Do not interpret separate directional intervals as a tested interaction.
